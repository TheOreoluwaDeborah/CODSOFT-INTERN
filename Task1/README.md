# CodSoft Internship – Task 1: VaultPay Signup Flow

## Overview

This task focuses on designing a **Signup and Login Flow** for a **Finance App** called **VaultPay**. The design reflects a high level of **security**, **trust**, and **user-friendliness**, as emphasized in the task brief.

VaultPay is a mobile platform that allows users to **secure their wealth and assets**, with features like **AR fund visualization** and **biometric authentication**.

---

## Deliverables

Five Mobile App Screens designed in Figma:

1. **Welcome Screen**  
   - App mascot and logo  
   - Two options: *Create New Account* and *Login*

2. **Login Screen**  
   - Email and password login  
   - Google authentication option  
   - “Forgot password?” link

3. **Signup Screen**  
   - Full form with name, email, DOB, password, and confirmation  
   - Checkbox for agreeing to Terms & Privacy Policy

4. **OTP Verification Screen**  
   - Enter 4-digit code  
   - Resend code timer and email confirmation

5. **Biometric Authentication Screen** (optional for submission but included for context)  
   - Face/fingerprint verification to reflect the importance of **security**

---

## Tools Used

- **Figma** – For UI design  
- **Fonts** – Sora (Headlines), Lato (Text), IBM Plex Mono (Numbers/AR)  
- **Color Scheme** – Deep Blue & Gold
