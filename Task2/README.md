# Task 2 - VaultPay Promotional Email Design (CodSoft Internship)

This task focuses on designing a **promotional email template** for VaultPay — a secure digital finance platform. The design includes both **desktop** and **mobile** versions of the email to ensure responsiveness and consistent branding across devices.

## Purpose
To create a visually appealing email that introduces VaultPay’s features and encourages users to explore the platform.

## Key Features Highlighted
- Secure your digital funds in a personal vault.
- AR-powered view of your assets.
- Multi-currency support.
- Easy sign-up and lifetime security.

## Design Overview
- **Desktop Email Template**: Structured with CTA button, intro text, visual hierarchy, and clean layout.
- **Mobile Email Template**: Optimized layout for readability and interaction on mobile screens.
