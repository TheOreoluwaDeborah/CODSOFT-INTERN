# 🧳 Triptique - E-commerce Web App Design

## Overview

This project was created as part of my internship tasks at CodSoft.  
It is a conceptual e-commerce platform called **Triptique**, specializing in **premium travel gear and accessories**.

The project includes the design of **four main pages**, focusing on **user experience**, **visual aesthetics**, and **responsive layout**.

---

## Pages Designed

1. **Landing Page:**  
   A clean and engaging introduction to the brand, featuring a hero section, featured categories, and call-to-action areas to browse collections.

2. **Product Listing Page:**  
   Displays a grid of products based on selected categories. Users can browse, filter, and add items to the cart easily.

3. **Product Details Page:**  
   A detailed view of a selected product, showcasing images, product description, price, color and size selection options, and "Add to Cart" functionality.

4. **Cart Page:**  
   Summarizes the selected products, allowing users to update quantities, apply coupon codes, view their order totals, and proceed to checkout.

---

## Features

- Smooth navigation flow between pages
- Clean, minimalistic, and professional design
- Coupon code functionality design (Cart page)
- "You Might Also Like" product recommendation section
- Consistent branding, typography, and color palette
- Responsive layout for a user-friendly experience across devices
